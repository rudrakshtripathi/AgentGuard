# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. Include the affected component, steps to reproduce, impact, and any suggested mitigation. Do not open a public issue containing an exploitable vulnerability.

## Scope

This policy covers the AgentGuard source code, its policy gateway, mock tools, and the bundled demo configuration. Do not test against systems or accounts you do not own or have permission to assess. The project is an academic demo, not a production security product; it has no guaranteed response time or service-level commitment.
